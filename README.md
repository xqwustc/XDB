# 课题一 · 精准诊断

领域感知的大模型自适应测评交互 Demo。纯 HTML、CSS、JavaScript，无依赖，无构建步骤，离线可用。

## 打开与演示

直接用浏览器打开 `index.html`，在项目主页点击「进入演示」，或直接打开 `demo.html`。也可在当前目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:8765/>。

1. 点击两个上传区域，载入示例模型 `Qwen2.5-7B-Instruct` 和题库 `ScienceBench.jsonl`。
2. 点击「开始测评」。污染审计完成后自动进入自适应测评，约 24 秒后生成诊断结果。
3. 运行中可以暂停、继续或切换 2× 速度。浏览器切换到后台时进度会冻结。
4. 点击诊断页的能力维度，查看「学科 → 模块 → 知识点」详情。默认显示的薄弱知识点包括「有机反应中的催化剂使用」。
5. 用左侧导航回看已完成的步骤。运行中切换步骤会终止并丢弃当前阶段；回到配置页点击「开始测评」可重新运行。
6. 「重新演示」回到未配置状态；顶部全屏按钮用于投屏展示。

当前展示四步流程，第五步「能力维度持续扩展」的页面与入口暂时隐藏，代码保留。将 `app.js` 中的 `visibleStageCount` 改回 `5` 即可恢复。

## 示例数据

主要演示数据在 `app.js` 的 `demo` 对象中维护，结果摘要等固定文案位于 `demo.html`。模拟载入不会读取、上传文件或调用模型；审计结果、答题响应、置信区间、诊断和扩维均用于展示，不是真实统计计算。

- 原始题库：1,000；可信题库：842；估计污染率：12.6%；95% CI：[9.8%, 15.4%]。
- 污染率是风险估计，可信筛选有独立阈值，因此排除的 158 条不等于污染率乘以原始题量。
- 最终测评：62 / 842；能力：0.69；95% CI：[0.62, 0.76]；题量节省：92.6%。节省比例仅表示示例题量变化，不代表已验证的真实测评精度。
- 六维分数：数学 0.82、物理 0.74、化学 0.36、生命 0.68、材料 0.61、地学 0.65。
- 扩展维度（暂时隐藏）：实验设计 0.52。

## 文件

- `index.html` / `home.css`：项目主页、两项功能介绍与项目支撑。
- `demo.html`：演示界面、流程导航、控制按钮，以及保留的第五步界面。
- `styles.css`：白底蓝色视觉、响应式布局、减少动态效果支持。
- `app.js`：示例数据、演示状态、计时器、SVG 图表、知识点下钻。

## 验证要点

- 尚未载入两个示例时，开始测评应不可点击。
- 按顺序自动进入审计、测评、诊断，结果应与上方示例一致。
- 暂停时数字应停止变化；继续与加速后应正常完成。
- 回看、重播和运行中重置不应残留计时器或跳到旧任务的步骤。
- 六个能力维度均可下钻；第五步导航、流程概览中的扩展项、扩展入口与页面均不可见。
- 桌面与手机宽度下不应出现页面水平滚动。

## 三课题统一版本（2026-10-23 更新）

从项目主页进入 `demo.html`，可连续演示：

- 课题一（01–04）：配置、可信性审计、自适应测评、认知诊断。
- 课题二（05–07）：薄弱环节训练、模型自主提问、专家知识收集。
- 课题三（08–11）：对话知识精炼、薄弱知识定位、知识更新与测试、编辑版本管理。

课题二收集页新增“进入知识精炼”入口，载入已提供的催化剂示例；完成课题二的专家确认与知识收集后，侧栏才解锁课题三入口。课题三定位过程以弹窗双卡展示层级筛选及参数两轮扫描，依次识别高相关参数、区分通用与专业参数，并生成概念稀疏掩码。

三个课题共用顶部栏、分组导航和全局重置。返回已完成步骤不会清空课题三状态。“重新演示”重置所有课题，本地已保存快照不删除。

课题三静态资源位于 refinement/，通过 iframe 隔离原有脚本与样式，并用限定发送窗口的 postMessage 同步导航、进度及重置；支持直接 file:// 打开。integration.js / integration.css 负责统一外壳。课题三原独立目录仍保留。

数据范围：课题三仍是固定催化剂示例的精炼演示，并非任意文本的通用精炼器。课题二使用内置示例完成确认时，传递相同知识记录的确认时间与来源信息；用户手写不同内容时，课题三继续载入已提供的固定示例，不将固定精炼结果标作手写内容的计算结果。

本次验证：JavaScript 语法检查、独立与内嵌资源同步检查、课题二默认十条对话一致性检查，以及 Node VM 中的前置门禁、四步导航、保存解锁、重置和旧轮次消息隔离。未进行本次真实浏览器视觉验收。

课题三效果评测为四栏：事实知识可靠性、泛化性、局部性和程序性知识应用，支持一键自动测试和手动对话。训练展示通用参数保护与专业参数更新；保存后进入独立的编辑版本管理页，支持历史详情、重命名和导出。默认快照名称使用完整模型名 Qwen2.5-7B-Instruct，并附任务说明。

展示主题：白色基底、浅灰蓝侧栏和卡片分区、深色正文、蓝色主操作、绿色完成状态；图表和弹窗同步使用浅色主题。左上角品牌为“人机交互自主进化”。


## 导航一致性修复（2026-10-13）

统一版课题三以前序“专家知识收集已完成且记录已确认”为进入条件，按钮状态和事件处理同时校验。初始 HTML 默认禁用入口，避免脚本加载期间越级进入。

三个课题使用相同的侧栏布局，桌面保留主标题和副标题，小屏统一使用紧凑导航。侧栏可独立滚动，不再随进入课题三改变字号、隐藏副标题或隐藏当前测评对象。

重新采集或修改专家回答，会使课题三旧结果失效并重新锁定；全局重置恢复初始状态。跨工作区切换暂停隐藏的课题三任务，返回继续运行。消息带有当前轮次标记，旧轮次状态不会覆盖重置后的导航；重置同时恢复示例来源，避免残留旧确认时间。

## 首页历史测评结果（2026-10-20）

首页配置区下方新增历史测评列表，展示完成时间（北京时间）、模型和题库、综合能力及置信区间、测评题量和主要薄弱项。点击「查看结果」可在独立弹窗中查看能力雷达图、污染审计摘要和薄弱知识点，不改变当前任务或解锁后续课题。

首次打开提供三条标记为「预置示例」的历史结果。实际完成一次演示后，结果作为「本地演示」保存至当前浏览器的 localStorage，最多保留 20 条本地记录；刷新或重新演示不会删除历史。回看诊断页面不会重复保存。浏览器禁止存储时会显示提示，当前页面内仍能回看。不同浏览器或 file:// 与 HTTP 打开方式之间不共享记录。

新增 `history.js` 和 `history.css`，沿用现有浅色主题。历史数据只用于演示，不代表真实测评或模型进步。
