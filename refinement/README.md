# 课题三 · 三环节独立演示

入口：index.html。浏览器直接打开即可，无需构建和联网。此目录为本轮新实现，未修改课题一、二系统，也未覆盖旧的 LLM knowledge refinement 工作台。

## 操作

1. 点击“传入对话文件”，直接载入 expert-catalyst-knowledge.jsonl 的内置副本。点击“精炼对话”，约 8 秒后弹窗展示事实问答和程序性知识；紫色标出催化实例内容，通用逻辑使用正文和蓝色。
2. 事实定位默认 Top-K=3。点击开始定位，观察 28 层结构的扫描、概率变化、柱状图与热图。程序定位默认 4 对实例、Top-K=4；先生成正反实例，再对比定位。实例数量可选 2/4/6/8，K 可选 2/3/4/6；可展开全部实例或点击组件详情。两类可独立运行，全部完成后进入训练。
3. 点击“开始训练”，观察 100 步模拟 loss 和定位组件写回状态。训练完成后通过弹窗进入效果测试，点击“运行全部测试”，依次生成四个测试回答：事实知识可靠性、泛化性、局部性，以及程序性知识应用，不展示更新前后对比。全部测试完成后，可以“保存本次模型参数”，并导出 JSON 快照。

## 行为

- 精炼、定位与训练完成时弹窗呈现结果和下一步入口；关闭后仍可回看。训练与测试使用独立页签。
- 支持定位与训练停止、重新运行、导航回看、全屏和全部重置。
- 调整 K、实例数或重新定位会清除对应分支及下游训练、测试状态。重新精炼会清除两类定位。
- 页面隐藏时计算进度冻结。切换页面时当前任务继续运行，已有结果可回看。
- 保存将演示快照写入浏览器 localStorage；重置不删除已保存快照。导出为可下载 JSON。

## 数据与边界

sample.js 由用户给出的 ../expert-catalyst-knowledge.jsonl 原样序列化生成。事实内容来自 knowledge / verification；程序内容来自 knowledge / boundary / supplement。

正反例和测试回答均为派生演示样例。定位分数、概率和曲线为模拟数据。层数对应 Qwen2.5-7B 的 28 个 decoder 层；仅将 Attention 与 MLP 作为候选参数模块，Residual 是残差流而非独立参数模块，不再纳入更新候选。示意层号 L1–L28 对应实现中的 layers.0–layers.27。图中扰动的是模块输出，训练更新的是所选模块的参数，两者不是同一操作。程序性多实例对比是本演示的方法设定，不代表已验证的通用定位结论。Top-K 按组件数量选择，训练范围合并两类结果并去重。

保存的是模拟参数记录，含来源 ID、知识、定位配置、组件范围、loss 轨迹、2×2 玩具更新量和测试回答；不含真实模型权重，不可用于模型推理。

## 文件

- index.html：统一风格的页面框架。
- styles.css：直接复制课题一、二系统基础样式。
- learning.css：三环节页面及图表布局。
- sample.js：专家 JSONL 内置副本，支持 file:// 离线打开。
- app.js：示例内容、模拟计算、图表、流程状态和保存导出。

展示主题：白色基底、浅灰蓝侧栏和卡片分区、深色正文、蓝色主操作、绿色完成状态；图表和弹窗同步使用浅色主题。左上角品牌为“人机交互自主进化”。
